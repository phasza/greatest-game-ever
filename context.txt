📤 CLIENT → SERVER MESSAGES

1. createRoom
   json{
   "type": "createRoom",
   "payload": { "playerName": "Alice" }
   }
2. joinRoom
   json{
   "type": "joinRoom",
   "payload": { "roomCode": "X7K9", "playerName": "Bob" }
   }
3. submitAction
   json{
   "type": "submitAction",
   "payload": {
   "action": "attack",
   "shownAction": "defend"
   }
   }

action: real action to execute
shownAction: what opponent sees (null = hide)

4. readyNextRound
   json{
   "type": "readyNextRound",
   "payload": {}
   }
5. leaveRoom
   json{
   "type": "leaveRoom",
   "payload": {}
   }

## 🎲 RESOLUTION MATRIX

| P1 ↓ \ P2 → | Attack | Defend | Charge | Heal | Super |
|-------------|--------|--------|--------|------|-------|
| **Attack**  | Both -1 | Blocked | P2 -1, P2 +1E | P2 -1 (no heal) | Blocked |
| **Defend**  | Blocked | Nothing | Nothing | Nothing | Blocked |
| **Charge**  | P1 -1, P1 +1E | P1 +1E | Both +1E | P1 +1E | P1 -3, P1 +1E |
| **Heal**    | P1 -1 (no heal) | P1 +1HP | P1 +1HP | Both +1HP | P1 -3 (no heal) |
| **Super**   | Blocked | Blocked | P2 -3, P2 +1E | P2 -3 | Both -3 |

**Resolution Rules:**
1. Apply modifier effects (e.g., bothLoseHP)
2. Check energy costs (Super needs 2 Energy, or 1 with cheapSuper)
3. Resolve interactions (see matrix)
4. Apply damage modifiers (e.g., doubleDamage)
5. Update HP/Energy
6. Check win condition

**Notes:**
- Max HP: 10
- Starting: HP 10, Energy 0
- Attack interrupts Heal (no healing occurs)
- Defend blocks both Attack and Super

## 📝 EXAMPLE FLOW
```

1. Client A connects
2. Server → { type: 'connected', payload: { clientId: 'abc123' } }

3. Client A → { type: 'createRoom', payload: { playerName: 'Alice' } }
4. Server → { type: 'roomCreated', payload: { roomCode: 'X7K9', playerId: 'abc123' } }

5. Client B connects & joins
6. Server → { type: 'connected', payload: { clientId: 'def456' } }
7. Client B → { type: 'joinRoom', payload: { roomCode: 'X7K9', playerName: 'Bob' } }
8. Server → { type: 'roomJoined', payload: { roomCode: 'X7K9', playerId: 'def456' } }

9. Server → Both: { type: 'gameStarted', payload: {...} }
10. Server → Both: { type: 'timerUpdate', payload: { timeRemaining: 15 } }

11. Client A → { type: 'submitAction', payload: { action: 'attack', shownAction: 'defend' } }
12. Server → A: { type: 'actionSubmitted', payload: { success: true } }
13. Server → B: { type: 'opponentShownAction', payload: { shownAction: 'defend' } }

14. Client B → { type: 'submitAction', payload: { action: 'charge', shownAction: null } }
15. Server → B: { type: 'actionSubmitted', payload: { success: true } }
16. Server → A: { type: 'opponentShownAction', payload: { shownAction: null } }

17. Server → Both: { type: 'roundResult', payload: {...} }

18. Clients → { type: 'readyNextRound', payload: {} }
19. Server → Both: { type: 'nextRound', payload: {...} }

(Loop until gameOver: true)

## 🧪 TEST SCENARIOS

### 1. Basic Combat
```

P1: attack (shown: attack)
P2: defend (shown: hide)
→ P2 blocks, no damage

```

### 2. Energy Build-Up
```

Round 1: P1 charge → Energy = 1
Round 2: P1 charge → Energy = 2
Round 3: P1 super → P2 HP -3, P1 Energy = 0

```

### 3. Successful Bluff
```

P1: attack (shown: defend) [bluffing defense]
P2: charge (believes P1 will defend)
→ P2 HP -1, P2 Energy +1

```

### 4. Double Damage
```

Modifier: doubleDamage
P1: attack, P2: charge
→ P2 HP -2 (doubled), P2 Energy +1

```

### 5. Must Reveal
```

Modifier: mustReveal
P1: attack (forced to show)
P2: defend (forced to show)
→ No mindgames, straightforward block
